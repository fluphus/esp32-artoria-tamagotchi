# SaveManager 使用说明

## 1. 运行方式

在 `SaveManager` 目录运行：

```powershell
py save_manager.py
```

按提示输入串口号、波特率、超时后，可选择：

- `st` 查询存档状态
- `ex` 导出指定槽到本地 `.bin`
- `im` 将本地 `.bin` 导入到指定槽
- `q` 退出

也支持命令行模式（示例）：

```powershell
py save_manager.py --port COM5 status
py save_manager.py --port COM5 export --slot 0 --out slot0.bin
py save_manager.py --port COM5 import --slot 1 --in slot0.bin
```

## 2. 导入后的槽位规则（重要）

导入完成后，系统会把“导入槽”作为活跃槽之一；再从另外两个槽中选“更旧”的那个作为另一活跃槽，二者参与后续轮换存档；剩下一个槽冻结保留，不再参与后续存档覆盖。

> “更旧”优先按 `sequence` 判断，必要时再用 `save_time` 判断；空/无效槽视为更旧。

## 3. 导入后时间设置

导入后会强制要求设置当前时间，作为后续成长和离线结算基准时间；该过程不会执行“从旧存档时间补算到现在”的离线结算。

## 4. 常见问题

- 串口无法打开：请先关闭 `pio device monitor` 或其他占用串口的软件。
- 导入超时：请确认导出与导入使用同一固件版本，并使用新导出的 `.bin` 文件。
