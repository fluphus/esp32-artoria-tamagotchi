# 👑 アルトリア・たまごっち (FGO バーチャルペット)

**ESP32-S3 (N16R8)** を搭載した、たまごっち風のバーチャルペットプロジェクトです。

あなただけのアルトリアを育てましょう！セイバー・リリィから旅を始め、彼女の成長を導きます。お世話やコミュニケーションに応じて、アーチャー、ランサー、ライダーなど、様々なクラスへと進化します。

## ✨ 機能 (コアロジック実装済み)
* **進化システム：** ペットのステータス（健康度、真面目さなど）に基づく複数の成長ルート。
* **時間・日付管理：** 日替わりのリセットや、食事を与えなかった場合のペナルティを処理する内部時計を内蔵。
* **永続ストレージ：** チェックサム検証付きの自動セーブ/ロードシステム（電源喪失時のデータ破損を防止）。
* **インタラクティブなアクション：** 餌やり、つつく（Poke）、ステータス監視。

## 🚧 現在のプロジェクト状況
**開発中 (バックエンドのみ)**

現在、プロジェクトは**コアロジックとステートマシン**のみで構成されています。
* ❌ GUI / 画面表示はまだサポートされていません。
* ✅ **シリアルポートデバッグ**を通じてすべての機能が動作可能です。

シリアルモニタからコマンドを送信することで、アルトリアと対話できます。ハードウェアUI（画面とボタン）の統合は今後のアップデートで予定されています。
